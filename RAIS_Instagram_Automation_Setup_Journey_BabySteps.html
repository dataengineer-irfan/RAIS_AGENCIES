Step 5: Generating Access Tokens & Finding Account ID

🔑 Extracting the Secret API Keys
  • Graph API Explorer: Opened Meta's developer console (developers.facebook.com/tools/explorer).
  • Short-Lived User Token: Generated an initial access token and authorized your account.
  • Long-Lived Token Exchange: Because short-lived tokens expire in 1 hour, we exchanged it for a 60-day / permanent Long-Lived Token so code runs unattended.
  • Finding the Instagram Account ID: Queried GET /me/accounts?fields=instagram_business_account.
  • The Output: Meta returned your permanent Instagram Business Account ID: 29157923917158606.

STEP 7 OF 7

Step 7: How Our Python Code Publishes to Instagram

⚡ The 4-Step Automated Publishing Protocol
  • 1. Video Upload to CDN: Meta API cannot read local C: drive files. The script uploads the 7.6MB MP4 to a public CDN (uguu.se) to get a direct HTTPS stream URL.
  • 2. Container Creation: Python sends a POST request to https://graph.instagram.com/29157923917158606/media with media_type='REELS', the video URL, and clean Telugu/Hindi caption.
  • 3. Transcode Polling: Meta servers transcode the video. Python polls Meta every 4 seconds until status reaches FINISHED.
  • 4. Live Broadcast: Python calls /media_publish. The video instantly appears live on your profile grid! Python then posts a pinned top comment with clickable WhatsApp links.
